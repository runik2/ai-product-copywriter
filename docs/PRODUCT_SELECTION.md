# Выбор товаров

Команда `feed pick` ранжирует реальные офферы по числу параметров, длине описания и признакам КИП. Первый товар — наиболее полный прибор; второй — прибор из другой категории с более скудными данными, чтобы показать `missing_data`. В `examples/inputs/` сохраняются выбранные JSON, а исходные XML-фрагменты — в `examples/inputs/raw/`.
