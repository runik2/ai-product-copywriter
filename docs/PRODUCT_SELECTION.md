# Выбор товаров

## Как выбраны

`feed pick` ранжирует офферы по признакам КИП, числу параметров и длине описания. Первый
товар — наиболее полный прибор из фида; второй — прибор из другой категории с более
скудным набором полей, чтобы показать `missing_data` на реальном примере.

В репозитории сохранены:

- `examples/inputs/product_1.json` — `offer_id=73083`, testo мини-термометр;
- `examples/inputs/product_2.json` — `offer_id=371262`, ПРОМА-ТСП-103-80-Г-Pt1000-А-4;
- `examples/inputs/raw/product_1.xml`, `product_2.xml` — исходные фрагменты YML;
- `examples/inputs/raw/product_1.page.json` — исходный JSON-LD страницы первого товара.

## Обогащение первого товара

- Источник: `https://www.souz-pribor.ru/product/testo-mini-termometr-poverkhnostnyy/`.
- Дата снимка: **2026-11-09**.
- Добавлено из JSON-LD: `Верхний предел измерений=300`, `Нижний предел измерений=-50`,
  `Измерение влажности=Нет`, `Память=Нет`, `Диапазон измерений=-50 … +300 °C`.
- Описание расширено подтверждёнными фразами страницы: поверхностный мини-термометр,
  расширенный измерительный наконечник, большой чёткий дисплей, индикатор ресурса батареи.
- Удалено: «Привлекательная цена», «Популярные подборки» и прочие рекламные/навигационные
  фразы. Текст очищен с разделителями на границах тегов и строк, поэтому слова больше не
  слипаются (`термометрПривлекательная`).
- Полный JSON-LD без HTML-дампа: `examples/inputs/raw/product_1.page.json`.

## Второй товар

У второго товара страница `/product/tsp-k/` — групповая карточка серии ТСП-К. Поэтому её
свойства (`Выходной сигнал`, `Взрывозащита`, `Присоединение к процессу`, `Конструктивное
исполнение`) описывают серию, а не конкретный вариант Pt1000. Они сохранены как источник
страницы, но `missing_data` по-прежнему требует диапазон измерений и тип чувствительного
элемента. Для строгого разбора без групповых свойств используйте `feed pick` без `--enrich`.

## Воспроизведение

```bash
python -m card_assistant feed fetch
python -m card_assistant feed pick --feed data/feed.xml --ids 73083,371262 --enrich
python -m card_assistant generate examples/inputs/product_1.json examples/inputs/product_2.json --out examples/outputs
python -m card_assistant check examples/outputs
```

Имена файлов результатов: `{offer_id}_{ascii-slug}.json` и `.md`.
