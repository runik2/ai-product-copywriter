# Решения

- Характеристики формируются кодом дословно из `specs`; LLM не является источником технических фактов.
- Код проверяет числа и рискованные утверждения. Честность важнее формального минимума в 800 символов: при недостатке исходных фактов остаётся предупреждение.
- YML скачивается в `data/` и не коммитится. В репозитории есть компактная синтетическая фикстура только для тестов.
- API совместим с OpenAI; в `.env` можно задать DeepSeek через `OPENAI_BASE_URL=https://api.deepseek.com` и `OPENAI_MODEL=deepseek-flash`.

Возможные улучшения: кэширование, массовая обработка, эталонный набор качества, редактор правок, справочник типов и human-in-the-loop.
